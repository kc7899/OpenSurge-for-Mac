# 稳定网关研发进度

本页记录当前研发分支的实现与验证范围，不能作为整套功能完成声明。

## 已完成的基础工作

- `internal/routing`：纯决策策略、任意长度数字自然排序、按 ID 的顺序协调、额度头解析。
- 保持健康连接、当前来源优先、区域过滤、失败冷却、恢复两次确认、全失败 REJECT 决策。
- 检测结果绑定版本/指纹；串行执行器检查 revision 和当前选择，超时读回结果，不重复 PUT。
- 显式独立节点的多来源配置合成原型；保留 base DNS/规则，跨来源重名隔离，默认 REJECT。
- provider/链式依赖尚未物化时明确报错，当前原型未接入正式应用流程。
- 迁移订阅请求 UA 兼容修复，并保护 DNS 返回空地址时的读取边界。
