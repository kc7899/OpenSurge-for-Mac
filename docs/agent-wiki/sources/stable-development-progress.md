# 稳定网关研发进度

截至 2026-11-17，rc.3 修复真实动态池的节点详情/原名与单节点检测接口。rc.2 的名称修复漏掉了 provider 成员，原测试未覆盖此路径。这不是整套功能完成声明。
更新内容及包校验值见 [Fork 更新记录](../../../FORK-CHANGELOG.md)。

## 已接通

- 稳定优先自动选线后台定时器、手动检查、运行状态和原子持久化。
- 共享 Web/桌面界面：总开关、按 ID 的订阅顺序、检测/额度/冷却间隔、地区策略、当前出口和原因。
- 健康时保留节点；故障独立目标复测；当前来源优先；区域和额度过滤；故障冷却与两次恢复确认。
- 单一执行入口、最多四个并行探测、版本/指纹检查和选择超时读回；不调用完整应用/重载做日常切线。
- rc.2 通过受管 file provider 更新显式节点池，校验失败保留旧池；当前有效节点保留，被移除时验证替代再清理。
- rc.3 读取受管 provider 实际成员，显示原始节点名/国家标记/订阅名，内部 ID 保持为选择键；单节点检测走 provider healthcheck。
- 显式独立节点的多来源合成，保留基础 DNS/分流规则，跨来源命名隔离，默认 REJECT。
- 设置保存仅写草稿；首次多来源配置、静态池迁移或分流配置变化需显式应用，沿用原版事务；已迁移池的节点刷新使用 provider API。
- 订阅请求 UA 兼容修复；403/额度未知不当作耗尽。

## 已执行验证

- rc.3 真实隔离策略工作区验证动态池原名和检测，以及重复全量检测含失败目标时当前选择、进程、主配置和测试流量保持。404/认证错误与节点不可达分开处理。

- Go 全量测试通过；Web 40 个测试文件、402 个测试通过；桌面控制客户端 race 测试通过。
- 原版安装/卸载脚本的 9 项检查及核心构建缓存的 15 项检查通过。
- rc.2 的 routing/controlapi/mihomo race 测试通过；真实核心验证首次无缓存加载、节点新增/删除、保留选择及移除过渡，更新失败回滚验证通过。
- 独立真实核心验证跨来源选择、单节点测速保持选择、REJECT 与直连隔离，进程和配置保持不变。
- 三份仓库外私有订阅的 129 个候选完成合成静态校验；真实出口抽样中一条验证 US，另两条未验证。
- 后台健康周期测试验证只检查当前节点，不调用生命周期 runner；状态快照不共享可变 map。
- 本地 arm64 原生 App 与 PKG 构建完成；包内版本、架构、最低系统、签名完整性检查及 SHA256 校验通过。
- 用户已自行安装并启动预览版；只读检查确认 App 版本、网关/Mihomo 运行和自动功能启用。
- 通过当前出口访问 HTTPS 返回 200，地区为 US。跨 71 秒观察，Mihomo/dnsmasq PID 与运行配置修改时间均未变化；后续状态为 current_healthy，保留原节点及切换时间。此结论仅覆盖该观察窗口。

以上不代表完整物理客户端、IPv6、Tailscale、故障切换和长期运行已验收。
构建及检查没有替用户安装、切线或重载网关；用户自行安装后的运行状态单独记录。

## 尚未完成

- ChatGPT 专项证书异常检测/恢复尚未实现，当前仅有通用连通检测；历史提示的排查与边界见 [证书排查记录](chatgpt-tls-diagnostic.md)。

- 用户报告过检测后间歇 Google 不可用，后续又反馈不再掉线；根因未完整确认，不能把接口修复等同于全部断网问题已解决。

- 新设备自动登记、默认放行和 Tailscale 自动授权；当前保留原版设备行为。
- provider/链式依赖物化，当前遇到这些来源会明确报错。
- rc.2 已接通订阅刷新到动态 provider 的同步；旧静态池需一次显式迁移。完整物理迁移和长期刷新验收仍待完成。
- 完整的后台故障/并发/恢复端到端矩阵，以及新界面交互测试。
- IPv6、新设备/Tailscale 隔离网络验收和长期运行验证。
- GitHub Release 的安装包上传、签名与公证；当前仅提供本地未签名预览包。

该预览包不应被标记为完整正式产品，主分支仍保留上游基线，研发工作位于 development/stable-gateway。
